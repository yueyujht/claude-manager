## 一、产品概览

### 产品定位

claude管家 是一个 **Claude Code 本地状态仪表盘**，通过 Web 界面集中展示 Claude Code 的各项运行数据——Token 消耗、技能库、插件、会话、项目、配置、记忆、历史命令、执行计划等。

### 核心用户

- Claude Code 重度使用者
- 需要追踪 Token 消耗和成本的开发者
- 管理多个项目的 Claude Code 用户

### 技术栈

| 层 | 技术 | 评价 |
|----|------|------|
| 后端 | Node.js + Express 5.2 | ✅ 轻量合适 |
| 前端 | 纯 HTML/CSS/JS（无框架） | ✅ 新手友好，但随着功能增长维护成本会上升 |
| 图表 | Chart.js 4.4 CDN | ✅ 选择合理 |
| 渲染 | marked.js 11.1 CDN | ✅ 轻量 |
| 样式 | 原生 CSS 变量 + 深色主题 | ✅ 设计系统清晰 |

## 三、问题清单

### 🔴 严重问题（影响核心体验）

#### 1. 计划页无法查看内容
- **现状**：[plans.js:24-35](public/js/plans.js#L24-L35) 只展示文件名、大小、日期
- **影响**：用户看到计划列表但点不开，完全无法使用该页面
- **修复**：参考 skills.js 的 modal 模式，点击卡片弹出计划内容（marked.js 渲染）

#### 2. 图表渲染依赖 setTimeout hack
- **现状**：[dashboard.js:94-97](public/js/dashboard.js#L94-L97) 和 [tokens.js:74-77](public/js/tokens.js#L74-L77) 用 `setTimeout(100ms)` 等待 DOM
- **影响**：数据加载快于 DOM 更新时图表渲染失败（竞态条件）
- **修复**：使用 `requestAnimationFrame` 或在 renderContent 后回调

#### 3. 插件数量硬编码
- **现状**：[dashboard.js:138](public/js/dashboard.js#L138) `pluginCount: 2` 写死在后端
- **影响**：安装/卸载插件后仪表盘数字不变
- **修复**：后端动态读取 installed_plugins.json 统计

#### 4. 项目名显示为编码格式
- **现状**：Memory 页和 Projects 页显示 `E--Java-study-vibe-coding-demo` 这样的编码路径
- **影响**：用户看不懂项目名
- **修复**：统一使用 `displayProject` / `displayPath` 字段（后端已提供但前端未使用）

### 🟡 一般问题（功能缺口/体验）

#### 5. 无全局搜索
- 只能在技能页和历史页各自搜索，无法跨模块搜索
- **建议**：顶部栏增加全局搜索框，搜索项目名、技能名、命令、计划标题

#### 6. 无数据导出
- Token 统计、会话列表、命令历史均无导出功能
- **建议**：表格区域增加"导出 CSV"按钮

#### 7. Token 页缺少时间范围筛选
- 目前展示全部历史数据
- **建议**：增加"最近7天/30天/全部"切换

#### 8. 费用信息分散
- 仪表盘模型表、Token 页、项目表各自展示费用，无汇总费用页
- **建议**：增加独立的"费用概览"卡片或页面

#### 9. 会话页无法展开详情
- 只能看到表格式摘要，无法查看会话具体内容
- **建议**：点击行展开，显示会话的 JSONL 摘要（消息数、Token 数）

#### 10. 项目详情缺少 Token 数据
- 点击项目只显示记忆文件 + JSONL 文件名，无 Token 统计
- **建议**：关联 stats-cache.json 中的项目 Token 数据

#### 11. 无 URL 路由同步
- 页面切换不更新 URL hash，无法书签/分享特定页面
- **建议**：使用 `location.hash` 实现简单路由（`#dashboard`, `#tokens` 等）

#### 12. 自动刷新仅限仪表盘
- [app.js:93](public/js/app.js#L93) 只有 `currentPage === 'dashboard'` 时静默刷新
- **建议**：Token 页、会话页也应支持自动刷新

### 🟢 改进建议（增强/优化）

#### 13. 暗色/亮色主题切换
- 当前强制深色主题
- **建议**：顶部栏增加主题切换按钮，用 CSS 变量切换

#### 14. 键盘快捷键
- **建议**：`Ctrl+K` 全局搜索，`1-0` 切换页面，`R` 刷新

#### 15. 页面过渡动画
- 切换页面时内容直接替换，无过渡
- **建议**：简单的 fadeIn/fadeOut，提升体验流畅感

#### 16. 数据刷新动画
- 自动刷新时无任何提示
- **建议**：状态栏增加脉冲动画或"刷新中"文字提示

#### 17. 移动端适配
- 侧边栏固定 200px，在手机上占满屏幕
- **建议**：增加汉堡菜单 + 响应式布局（但优先级较低，这是桌面工具）

## 五、详细方案

### 5.1 计划页查看内容（P0）

**现状**：
```javascript
// plans.js — 点击卡片无反应
<div class="info-card">  <!-- 没有 onclick -->
  <div class="info-card-title">${escapeHtml(p.title)}</div>
  ...
</div>
```

**方案**：
1. 后端增加 `GET /api/plans/:file` 端点，返回 Markdown 内容
2. 前端卡片加 `onclick="openPlanDetail('${escapeHtml(p.file)}')"` 
3. 用现有 modal 组件 + marked.js 渲染

### 5.2 URL Hash 路由（P1）

**方案**：
```javascript
// app.js navigateTo 中增加
window.location.hash = page;

// 初始化时读取 hash
const initPage = window.location.hash.replace('#', '') || 'dashboard';
navigateTo(initPage);

// 监听浏览器前进/后退
window.addEventListener('hashchange', () => {
  const page = window.location.hash.replace('#', '') || 'dashboard';
  navigateTo(page);
});
```

### 5.3 全局搜索（P1）

**方案**：
- 顶部栏增加搜索输入框
- 输入后弹出下拉面板，展示匹配结果（项目/技能/命令/计划）
- 点击结果跳转到对应页面并高亮
- 搜索范围：所有已加载数据（不额外请求）

### 5.4 Token 时间范围（P1）

**方案**：
- Token 页图表上方增加按钮组：`[7天] [30天] [90天] [全部]`
- 前端对 `dailyTrend` 数据做切片（无需后端改动）
- 概览页的 Token 趋势图同步支持时间切换

## 六、总结

### 核心发现

claude管家 V1.0 是一个**基础扎实但细节粗糙**的产品。10 个页面覆盖了 Claude Code 的核心数据面，深色主题设计统一，API 设计合理。但存在以下核心短板：

1. **计划页半成品** — 有列表无详情，等于白做
2. **数据展示层面的硬编码** — 插件数写死、项目名编码显示
3. **交互细节粗糙** — 图表 setTimeout hack、无 URL 路由、无导出

### 最值得先做的 3 件事

| # | 任务 | 理由 |
|---|------|------|
| 1 | 计划页 + 项目名修复 | 让已有功能完整可用，成本极低 |
| 2 | URL hash 路由 | 让页面可分享、可书签，基础体验提升 |
| 3 | 全局搜索 + Token 时间筛选 | 最高频的日常使用需求 |

### 一句话

> **先补齐短板让 V1.0 完整可用，再做 V1.2 体验优化，V1.3 锦上添花。**
