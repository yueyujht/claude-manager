# Claude管家 — Web 仪表盘实现方案

## 背景

用户是开发新手，使用 Claude Code（VSCode 扩展 + DeepSeek API），希望有一个程序能全面展示 Claude Code 的运行状态，包括 Token 使用、技能列表、插件、会话历史、CLAUDE.md 配置、Memory 记忆库等。用户想做 Web 仪表盘而非桌面应用（空间占用小、开发简单）。

## 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| 后端 | Node.js + Express | 轻量、新手友好、天然支持 JSON |
| 前端 | 纯 HTML/CSS/JS | 不引入 React/Vue，降低学习曲线 |
| 图表 | Chart.js | CDN 引入，简单易用 |
| 样式 | 原生 CSS（深色主题） | 匹配用户 dark theme 偏好 |
| 图标 | Emoji / CSS 绘制 | 零依赖 |

## 后端 API 设计

### 基础约定
- 所有 API 前缀 `/api`
- 返回 JSON 格式
- 只读访问 `.claude/` 目录，不写回
- 数据源路径：`C:\Users\jht25\.claude\`（可配置）

### API 清单

| 方法 | 端点 | 说明 | 数据来源 |
|------|------|------|---------|
| GET | `/api/dashboard` | 仪表盘汇总（Token、会话数、技能数等） | stats-cache.json + sessions + skills |
| GET | `/api/tokens` | Token 使用详情（按模型、按日期、按项目） | stats-cache.json + backups |
| GET | `/api/skills` | 技能列表（名称、描述） | skills/*/SKILL.md |
| GET | `/api/skills/:name` | 单个技能详情 | skills/:name/SKILL.md |
| GET | `/api/plugins` | 插件列表 | plugins/installed_plugins.json |
| GET | `/api/sessions` | 活跃会话列表 | sessions/*.json |
| GET | `/api/projects` | 项目列表及会话数 | projects/ 目录扫描 |
| GET | `/api/projects/:name` | 项目详情（会话、memory） | projects/:name/ |
| GET | `/api/config/claude-md` | 全局 CLAUDE.md 内容 | claude.md |
| GET | `/api/config/settings` | settings.json（脱敏） | settings.json |
| GET | `/api/memory` | 所有记忆列表 | projects/*/memory/ |
| GET | `/api/memory/:project` | 项目记忆详情 | projects/:project/memory/ |
| GET | `/api/history` | 命令历史（分页） | history.jsonl |
| GET | `/api/plans` | 执行计划列表 | plans/*.md |

### 布局结构（单页应用）

```
┌──────────────────────────────────────────────┐
│  🔵 Claude管家                    [刷新] [⚙] │  顶部导航栏

│ 📁 项目   │                                   │
│ 📝 Config │                                   │

│ 📋 历史   │                                   │
├──────────┴───────────────────────────────────┤

└──────────────────────────────────────────────┘
```

### 各页面内容设计

**1. 仪表盘概览（首页）**
- 4个统计卡片：Token 总消耗、活跃会话数、技能数、项目数
- Token 使用趋势图（Chart.js 折线图）
- 按项目 Token 消耗柱状图
- 最近会话列表（最新5条）

**2. Token 详情页**
- 按模型分组 Token 用量表（input/output/cache）
- 每日 Token 消耗趋势图
- 按项目分组消耗饼图
- 费用估算汇总

**3. 技能页**
- 24个技能卡片网格，每个显示名称+描述
- 点击展开详情（SKILL.md 完整内容）
- 搜索过滤

**4. 插件页**
- 已安装插件卡片
- 插件市场信息

**5. 会话页**
- 活跃会话列表
- 会话详情（PID、入口、版本）

**6. 项目页**
- 7个项目卡片
- 每个项目显示会话数、Token 消耗、memory 数量
- 点击进入项目详情

**7. Config 页**
- 全局 CLAUDE.md 内容（带语法高亮的 Markdown 渲染）
- settings.json 概要（隐藏敏感信息如 token）

**8. Memory 页**
- 按项目分组显示记忆文件
- YAML front matter 元数据展示

**9. 历史页**
- 命令历史列表
- 按项目/时间过滤

## 数据刷新策略

- **启动时**：全量加载所有数据
- **手动刷新**：点击刷新按钮 → 重新请求所有 API
- **定时轮询**：后台每30秒静默刷新仪表盘数据（仅 `/api/dashboard`）
